🛒 Amazon Sales Analysis Dashboard

📊 Overview
This project presents an interactive Amazon Sales Dashboard designed to analyze and visualize e-commerce sales performance across India. It provides real-time insights into product categories, courier performance, order status, and sales trends.
The dashboard helps identify top-performing states, categories, and shipment types, offering valuable insights for data-driven business decisions.


🚀 Key Features
✅ Comprehensive Sales Overview — total quantity, revenue, product categories, and shipment stats at a glance.
✅ Category & Courier Analysis — break down quantities and sales trends by product category and delivery method.
✅ Order Status Tracking — visualizes shipped, unshipped, pending, and cancelled orders.
✅ Regional Insights — interactive map showing quantity distribution by Indian state.
✅ B2B vs B2C Analysis — understand business vs consumer sales proportions.
✅ Dynamic Filtering — analyze data across time periods and categories using built-in filters.


🧰 Tools & Technologies
Data Processing: Python (Pandas, NumPy)
Visualization: Tableau Desktop
Geospatial Mapping: Mapbox integration
Data Source: Amazon Sales Dataset (cleaned and pre-processed using Tableau Prep / Excel)


📈 Insights Derived
Maharashtra and Karnataka are the top contributors to total sales quantity.
Majority of orders are standard shipped, with very few cancellations or returns.
Amazon.in accounts for over 99% of total sales, highlighting marketplace dominance.
B2C transactions are the major revenue source.
